## What is the Agentic DevOps Advanced Specialization?

The **Agentic DevOps Advanced Specialization** is a Microsoft + GitHub partner credential validating deep capability in modern, AI-assisted software delivery on Azure and GitHub Enterprise Cloud. It signals that your organisation can:

- Run **secure SDLC at scale** with GitHub Advanced Security, GitHub Actions, and Azure-backed runners
- Adopt and operate **agentic AI tooling** — GitHub Copilot Business / Enterprise, Copilot coding agent, Copilot Workspace, Copilot CLI, custom MCP servers — safely in regulated environments
- Migrate workloads from **Azure DevOps to GitHub** with minimal disruption
- Stand up **golden developer environments** with Microsoft Dev Box and GitHub Codespaces
- Deliver measurable outcomes against **operational excellence** and **security** Well-Architected pillars

## Why pursue this specialization?

The benefits compound across sales, delivery, and recruiting.

| Benefit | Details |
|---|---|
| **Differentiation** | A small number of partners hold it early — high visibility for the next 12–18 months |
| **Co-sell eligibility** | Priority co-sell referrals from Microsoft + GitHub field sellers |
| **Marketing assets** | Specialization badge, Microsoft-approved marketing collateral |
| **Partner Finder visibility** | Appear in filtered customer-facing searches |
| **Customer confidence** | Independent audit signal for AI-assisted SDLC capability |
| **Talent magnet** | The specialization is a strong recruiting signal for senior platform engineers |

## How this guide helps

This repository is structured as an **engagement toolkit**, not just an audit checklist. It covers four use cases:

1. **Pass the audit** — one page per control with evidence checklist, guidance, and common gaps.
2. **Productise the offering** — engagement playbook from offering one-pager through definition of done.
3. **Deliver to a reference customer** — discovery workshop kit, WAF assessment, reference architectures, customer deliverable templates (HLD, LLD, runbook, KT plan, hypercare plan).
4. **Innersource** — every consultant who delivers an engagement contributes improvements back via PRs and lessons-learned issues.

## Specialization scope

The audit assesses both general organisational maturity and Agentic DevOps-specific capability.

| Module | Scope |
|---|---|
| **Module A** | General organisational requirements (shared across all Advanced Specializations) |
| **Module B** | Agentic DevOps — capability, ACR performance, customer diversity, certifications, audit readiness, onboarding assets |

## Target consultant persona

This toolkit is calibrated for a **senior DevOps / platform engineer**:

- Comfortable in GitHub Enterprise Cloud administration (orgs, EMU, SSO, audit log streaming)
- Has shipped GitHub Actions pipelines with self-hosted Azure-backed runners and OIDC federation
- Has used at least one of Copilot Business / Enterprise / coding agent / Workspace / CLI on a real codebase
- Familiar with Azure DevOps for migration scenarios
- Background in .NET, JVM, or modern web — comfortable with the SDLC end-to-end
