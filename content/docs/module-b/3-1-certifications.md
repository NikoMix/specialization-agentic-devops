## What the Auditor Checks

The auditor verifies that **at least five unique individuals** in your organisation hold the required certifications, with each certification held by at least one person.

**Typical questions:**

- Who holds AZ-400 / GitHub Actions / GitHub Advanced Security / GitHub Copilot certifications?
- Are the certifications active (not expired)?
- Are the certificate holders currently employed by the partner organisation?

---

## Required Evidence Checklist

The four items below cover the cert mapping plus the per-individual transcript proof.

| # | Evidence Item | Accepted Formats | Status |
|---|---|---|---|
| 1 | **Certification mapping table** (individual → cert → expiry) | Excel, PDF | ⬜ |
| 2 | **Microsoft Learn transcript** per individual (for AZ-400) | PDF, Verification link | ⬜ |
| 3 | **GitHub certification badge** per individual (Actions, GHAS, Copilot) | PDF, Credly link | ⬜ |
| 4 | **Employment confirmation** for each cert holder | Signed letter, HR system screenshot | ⬜ |

### Verification Links

Where possible, include public verification URLs:

- Microsoft Learn: `https://learn.microsoft.com/api/credentials/share/...`
- GitHub Certifications (via Credly): `https://www.credly.com/badges/...`

### Employment Confirmation

A short signed letter from HR or an export of the HR system showing employment status is sufficient.

## Common Gaps

| Gap | Remediation |
|---|---|
| AZ-400 holder left the organisation | Identify replacement; book renewal exam for an internal candidate within 2 weeks |
| GitHub cert is expired | Re-take exam — GitHub renewal is straightforward |
| Cert holder has cert but no transcript link | Ask them to share their Microsoft Learn / Credly profile publicly |
| Only 4 individuals across the 4 certs | Have one additional team member take any one of the four certs |
