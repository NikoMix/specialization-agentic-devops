Module A assesses **general organisational maturity** and is common to every Microsoft Advanced Specialization. If your organisation already holds another specialization, most of this evidence can be reused — refresh the dates and re-export the documents.

| Control | Focus | Typical evidence |
|---|---|---|
| [1.1 Organisational Data](/docs/module-a/1-1-organizational-data/) | Legal identity and structure | Articles of incorporation, org chart, key personnel |
| [1.2 Financial Documentation](/docs/module-a/1-2-financial-documentation/) | Financial standing | Annual statements, professional indemnity insurance |
| [2.1 Service Delivery Methodology](/docs/module-a/2-1-service-delivery-methodology/) | How you deliver | Delivery playbook, SOW template, RACI, kickoff/closure artefacts |
| [2.2 Quality Management](/docs/module-a/2-2-quality-management/) | How you assure quality | QMS policy, CSAT process, escalation procedure |
| [3.1 Customer Satisfaction](/docs/module-a/3-1-customer-satisfaction/) | Evidence of satisfaction | CSAT/NPS data, references, testimonials |
| [3.2 Complaint Handling](/docs/module-a/3-2-complaint-handling/) | How you handle failure | Complaint register, resolved case, root cause analysis |
| [3.3 Security & Privacy](/docs/module-a/3-3-security-privacy/) | Information security posture | InfoSec policy, GDPR evidence, breach procedure, training records |

Track collection status for all seven on the [Evidence Tracker](/docs/evidence-tracker/).
