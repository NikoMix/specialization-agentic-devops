This page is a **snapshot** of the roadmap. The live backlog lives in [GitHub Issues](https://github.com/NikoMix/specialization-agentic-devops/issues) and [GitHub Projects](https://github.com/NikoMix/specialization-agentic-devops/projects). When the two disagree, GitHub Issues wins.

## Now (this quarter)

- Lock Module A and Module B controls against the official Microsoft guide once published
- Endorse the engagement playbook pages used in the first two pilot engagements
- Ship reference architecture diagrams (PNG/SVG) for RA-1 through RA-6
- First annual audit-evidence issue run via `create-issues.yml`

## Next (next quarter)

- Add a "Migration sizing calculator" workbook for ADO → GitHub
- Add a Copilot Adoption Scorecard workbook (per-team % active, % accepted suggestions, time-saved estimate)
- Add a Sentinel detection pack for Copilot coding agent + MCP server audit signals
- KT plan v2 with a self-paced learning path linking to MS Learn modules

## Later (this year)

- Hypercare retrospective pattern library
- Per-industry overlays (financial services, public sector, healthcare) on top of the base playbook
- MCP server reference implementation for ticketing (ServiceNow / Jira) and observability (App Insights)

## Out of scope

- Customer-specific content
- Tool reviews / vendor comparisons
- Anything that requires a Microsoft co-sell motion to ship (those belong on a separate co-sell tracker)

## How to influence the roadmap

Open an issue using the `lesson-learned` or `template-improvement` template. Roadmap is re-prioritised at the monthly content council triage.

<Aside type="tip">
  The roadmap is intentionally short. If you want to push something up the list,
  the fastest path is a PR that gets it most of the way to Reviewed.
</Aside>
