All four requirement categories must be satisfied **before** requesting an audit. Review each section carefully and confirm readiness with your Microsoft Partner Development Manager (PDM).

## Requirement 1 – Active Solutions Partner Designation

Your organisation must hold an **active** Solutions Partner designation. The most likely qualifying designation is shown below.

| Designation | How to verify |
|---|---|
| Solutions Partner for **Digital & App Innovation (Azure)** | Partner Center → Overview → Membership |

> ✅ **Evidence needed:** Screenshot of active designation from Partner Center, or the Partner Center PDF report showing designation status.

---

## Requirement 2 – Azure Consumed Revenue (ACR) Performance

Your organisation must demonstrate **$15,000 USD ACR in the last three months** across each qualifying pillar independently. The Agentic DevOps pillars below are drafts — confirm with PDM.

### Pillar 1 – App Platform + GitHub ($15,000 ACR)

Revenue from **Azure Application Platform services and GitHub products**, measured through:

| Service Category | Included Services |
|---|---|
| App Platform | App Service, Logic Apps, APIM, Functions |
| Container Services | AKS, ACA, ARO |
| Serverless and Supporting | Functions, Managed Redis |
| Developer Services | GitHub Enterprise Cloud, GitHub Advanced Security |
| AI-assisted SDLC | GitHub Copilot Business / Enterprise |

### Pillar 2 – Azure DevOps + Pipelines ($15,000 ACR)

Revenue from **Azure DevOps services and pipeline infrastructure**, measured through:

| Service Category | Included Services |
|---|---|
| Azure DevOps Services | Boards, Repos, Pipelines, Artifacts, Test Plans |
| Pipeline infrastructure | Hosted parallel jobs, Microsoft-hosted agent minutes |
| Runner infrastructure | Azure VMs / VMSS / AKS hosting self-hosted GitHub Actions runners |

### Customer Diversity Requirement

Your organisation must have **at least 3 unique customers** contributing to ACR in the last three months from the eligible pillars above.

The eligible association types are:

| Association Type | Abbreviation |
|---|---|
| Digital Partner of Record | DPOR |
| Partner Admin Link | PAL |
| Cloud Solution Provider | CSP |

> ✅ **Evidence needed:** ACR reports from Partner Center → Insights → Azure Revenue. Export and annotate to show pillar breakdowns and unique customer counts.

## Requirement 3 – Certifications

Your organisation must have **at least five individuals** pass the following certifications, with **each certification held by at least one individual**.

| Certification | Minimum holders | Exam / programme |
|---|---|---|
| DevOps Engineer Expert | 1 | AZ-400 |
| GitHub Actions | 1 | GitHub Actions certification |
| GitHub Advanced Security | 1 | GitHub Advanced Security certification |
| GitHub Copilot | 1 | GitHub Copilot certification (admin or developer track) |

<Aside type="tip">
  One individual may hold multiple certifications. A team of four could satisfy
  all four certification requirements, with one additional person holding any
  one of them again to reach the five-person minimum.
</Aside>

> ✅ **Evidence needed:** Microsoft Learn transcripts and GitHub certification badges for each individual. Prepare a mapping table (Name → Certification → Expiry Date).

---

## Requirement 4 – Third-Party Remote Audit

Your organisation must **pass a third-party remote audit** conducted by a Microsoft-approved audit firm.

The audit follows the steps below.

<Steps>
1. Confirm pre-qualification (Requirements 1–3 above are met)
2. Request audit via Partner Center → Advanced Specializations
3. Receive auditor assignment and kickoff call scheduling
4. Submit evidence package to the auditor
5. Complete the audit interview / review session
6. Address any remediation findings (if required)
7. Receive audit pass confirmation
</Steps>

> ✅ **Evidence needed:** This entire repository constitutes your evidence preparation package. Use [Module A](../module-a/1-1-organizational-data/) and [Module B](../module-b/1-1-agentic-devops-capability/) pages for control-level evidence.

## Quick Readiness Checklist

Use this list to confirm readiness before requesting the audit.

- [ ] Active Solutions Partner designation (Digital & App Innovation Azure)
- [ ] $15,000 ACR – App Platform + GitHub pillar (3-month trailing)
- [ ] $15,000 ACR – Azure DevOps + Pipelines pillar (3-month trailing)
- [ ] ≥ 3 unique customers contributing ACR
- [ ] AZ-400 held by ≥ 1 individual
- [ ] GitHub Actions cert held by ≥ 1 individual
- [ ] GitHub Advanced Security cert held by ≥ 1 individual
- [ ] GitHub Copilot cert held by ≥ 1 individual
- [ ] Total of ≥ 5 certified individuals
- [ ] Audit requested and evidence package prepared
